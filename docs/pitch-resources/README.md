# CryptoSure pitch resources

Five lengths of the same story, for whatever the moment allows. Pick the one
that fits the time you have and do not read past it.

| File | Length | Use it when |
|---|---|---|
| `01-one-liner.md` | one sentence | Introductions, slide titles, bios |
| `02-elevator-pitch.md` | about two minutes spoken | Hallway, judge table, first call |
| `03-one-paragraph.md` | one paragraph | Applications, cohort directories, email intros |
| `04-synopsis.md` | one page | Reviewer briefs, partner first-reads |
| `05-major-synopsis.md` | several pages | Anyone who asked a second question |

House rules for all of them: no acronym without its meaning in parentheses
on first use, no claim about what runs that has not been compiled or tested,
and the demo is always described as simulated data feeding real contracts.
